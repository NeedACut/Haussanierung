# Haussanierung – Sanierungsplaner

Übersichtliches Planungstool für Haussanierungen – läuft komplett im Browser (eine Datei, keine Installation).

- Alle Posten erfassen, mit Richtwerten nach Wohnfläche
- Automatische Fördervorschläge: BAFA BEG Einzelmaßnahmen, KfW 458 (Heizung), KfW 261 (Effizienzhaus), Fachplanung, iSFP, Steuerbonus §35c / §35a
- Finanzierungsrechner mit variablem Zins, Zinsbindung, Anschlusszins-Szenarien, Tilgungsplan
- Energieersparnis & Amortisation
- Speicherung lokal im Browser, Export/Import als Datei, CSV, Drucken/PDF

Öffnen: `index.html` im Browser – oder über GitHub Pages.

Alle Fördersätze ohne Gewähr (Stand November 2026), in den Einstellungen anpassbar.
